# Abutron Mobile — Step 26A

Cross-platform Android/iOS customer app.

## Safety
This Step 26A app is intentionally **read-only for trading**. It contains no order-entry or position-management controls.

## Development
1. Install Node.js compatible with Expo SDK 57.
2. Copy `.env.example` to `.env`.
3. Run `npm install`.
4. Run `npx expo install --fix`.
5. Run `npm run typecheck`.
6. Run `npm start`.

## Native builds
Use Expo/EAS or generate native projects after Step 26A server certification.
Store signing and App Store/Play credentials outside source control.
